
# 🍽️ Restaurant Website Clone - React.js

A fully responsive restaurant website clone built with React.js, focusing on component reusability using **React Props**.

### ✨ Features
- 📱 100% Responsive Design (Mobile, Tablet, Desktop)
- ♻️ Reusable Components using React Props
- 🍔 Dynamic Menu Rendering
- 🎨 Modern & Clean UI
- ⚡ Fast & Optimized

### 🛠️ Tech Stack
- React.js
- JavaScript (ES6)
- HTML5
- CSS3
- JSX

### 🚀 How to Run Locally
```bash
# Clone the repo
git clone https://github.com/hm137685-droid/Resturent-Website-clone.git

# Go to project folder
cd restaurant-website

# Install dependencies
npm install

# Start the project
npm start)
